# 권 구성 기록 v2 (2026-10-23)

## 결정
- 준비편(현 1~4장: 사료, 기존 학설, 사료 비판, 증거 DB)은 별도의 한 권으로 만든다. 작업 시작: 다음 주 월요일(2026-10-26).
- 2권 실행편 목차 작업도 같은 월요일로 잡혀 있었으므로 순서를 정해야 한다(미정).

## 권 구성(안)
| 권 | 이름 | 들어 있는 것 | 상태 |
|---|---|---|---|
| 1권 | 준비편 | 사료, 기존 학설, 사료 비판, 증거 DB (약 100쪽 이상으로 확장) | 월요일 시작 |
| 2권 | 방법편 | 서장, 기법 1~4(제약 전파, 지오레퍼런싱, 베이즈, 최소비용경로), 맺음말, 부록 | 조판본 있음(v23) |
| 3권 | 실행편 | 오픈소스, 오픈 데이터, 로컬 GPU, 기법 5~8(그래프, 지명 사전, 지명의 뜻, 교차 검증) | 목차 구상 |
| 4권 | 통합·지역 적용편 | 여덟 방법 비교, 서경 통합 추정, 네 지역 적용, 사료집 | 집필 중 |

## 영향
- 현재 조판본(book-vol1-v23)의 "1권 방법편"은 "2권 방법편"으로 이름이 바뀌고, 준비편 내용(1~4장)은 방법편에서 빠진다. 방법편 서장에서 "준비편을 먼저 읽을 것"을 안내한다.
- 표 0-1(책의 구성), 장별 안내(표 0-2), 표지(앞날개·뒷날개·부제), 판권면, 2권 목차의 1권 연결표를 모두 새 권 번호로 고친다.
- 표지 제목의 "여덟 가지 방법"은 전체 시리즈 기준이다. 각 권에 어느 방법이 들어 있는지 서장에 분명히 쓴다.
- 미정: 방법편 안에서 5~8장 번호를 1~4장으로 다시 매길지. 준비편 분리 후 방법편은 서장과 4개 기법 장으로 구성된다.
