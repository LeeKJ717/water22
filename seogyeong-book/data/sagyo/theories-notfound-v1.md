# 서경 위치 학설 장부 v1 - 못 찾은 것

작성 기준: 페이지에서 직접 확인한 것만 장부(seogyeong-theories-v1.csv)에 적었고, 아래는 확인하지 못해 비운 항목이다.

## 1. 후보지역별 공백
- 산동: 고려 서경을 산동에 두는 학설은 학술논문, 백과사전, 위키백과에서 찾지 못했다. 검색 결과에 산동 설정은 나오지 않았다. 장부에 산동 행 없음.
- 만주: 서경 자체를 만주에 두는 주장은 찾지 못했다. 만주 행 1건(허우범 2024)은 서경이 아니라 고려 서북계(박주·압록)를 길림성 일대로 보는 논문이며, 서경은 직접 다루지 않는다.
- 요하유역: 학술지에서 서경을 직접 요양 등으로 비정한 것은 최규흥 2023(초록)뿐이었다. 나머지는 인터넷 카페 게시글(2차자료)이거나 서경을 직접 다루지 않는 서북계 논문이다.

## 2. 서지 미확인 항목(이름은 페이지에 있으나 제목·연도 미확인)
- 하현강(1970): 아관 항목 참고문헌에 서경 관제 연구로 표기. 논문 제목 확인 못함.
- 최윤정: 최탄 항목 참고문헌에 동녕부 설치 배경 '재론' 논문으로 표기. 제목·연도 확인 못함.
- 정요근: 이덕일 칼럼이 비판자로 언급. 해당 비판의 논문·발언 원문 확인 못함. 서경 관련 정요근 논문은 찾지 못함.
- 정약용 서경압록부 자성북안설: 백과사전 항목에 학설 이름만 있고 근거 사료·저작명 없음.
- 서경압록부 평양설: 백과사전이 열거만 하고 주창자 표기 없음.
- 이화여대 박사학위논문 「고려 전기 서경세력의 연구」: 저자·연도가 페이지에 없음.
- 송영대 「고려의 주몽·동명 인식과 동명성왕 관념 성립」: 게재 연도가 PDF 본문에서 확인되지 않음(정신문화연구 41권 3호).

## 3. 찾으려 했으나 조사 범위 안에서 확인 못한 것
- 통설 평양설의 학설사(처음 누가 주장했는지, 예컨대 근대 이전 지리지 외의 연구사)는 확인하지 못했다. 장부의 평양설 행은 백과사전 서술과 평양을 전제로 쓴 논문들이다.
- 고려 서경 평양 위치를 직접 검증한 고고학 보고(대화궁·장락궁·임원궁성 발굴 등)는 확인하지 못했다.
- 동북아역사재단 공개 자료(동북아역사지도 서경·동녕부 표기 설명)는 검색 결과에서 해당 페이지를 열람하지 못했다.
- 국사편찬위원회 한국사데이터베이스 직접 열람은 하지 못했다.
- KCI 본문 전체, DBpia, RISS 본문은 초록 수준 이상 접근하지 못했다.
- 한국어 위키백과(평양직할시, 동녕부)는 허용 목록 밖이라 열람하지 못했고, 영문 위키백과 일부만 열람했다.
- 요하유역설 주창자 중 책 단행본(예: 인하대 고조선연구소 『고구려의 평양과 그 여운』, 2017)은 언론 보도로만 확인했다. 보도는 평양 위치가 시대에 따라 변했다는 취지와 서경이 평양에 설치됐다는 서술만 담고 있으며 고려 서경의 위치에 대한 구체적 주장은 없었다. 장부에는 넣지 않았다.

## 4. 고려 서경과 직접 무관해 장부에서 제외한 자료
(고구려·고조선·낙랑의 평양 위치 논의로, 고려 서경과 연결하려면 별도 근거가 필요함)
- 권순홍 2019 「고구려 '평양'의 변천과 전기 평양성의 위치에 관한 쟁점 검토」(역사문화연구 70집): 427년 이전 평양을 집안 일대, 이후를 현 평양으로 봄.
- 이도학 2014 「낙랑군의 추이와 영서 지역 낙랑」(동아시아고대학 34집).
- 정암 2020, 임찬경 2020, 이상훈, 정경일 2016, 김선숙 등: 평양·압록 관련이나 서경 위치 직접 언급 없음(김선숙은 황성 위치의 기준점으로 서경 언급).
- 김창현 2002, 이익주 상경 논문, 김종근·이상균, 임상선: 서경 위치와 무관.
- 환단학회지·역사와 융합 게재 논문 중 서경을 다루지 않는 것.
