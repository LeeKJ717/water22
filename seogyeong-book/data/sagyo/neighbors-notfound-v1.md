# 이웃 지명 좌표표 v1 - 확인 못 한 항목

조사 방식 제약: wikidata.org, GeoNames, ko.wikipedia, en.wikipedia 직접 접속은 프록시 정책으로 막혀(403/미허용) 있어 검색 결과에 나온 URL만 WebFetch(요약 모델 경유)로 읽었다. 좌표는 그 도구가 페이지에서 인용해 준 문자열이며 원문 대조는 하지 못했다.

## 좌표를 못 구한 항목 (행 제외)
- 대동강(大同江): 위키백과 Taedong River 인포박스에 source/mouth 좌표 없음. 한 미러 페이지(akarinohon)에 라벨 없는 좌표 38.86500, 125.52556만 있어 무엇을 가리키는지 불명이라 쓰지 않음. 하구 방면 참고점으로 남포(행 포함), 지류 보통강은 안산교 지점(행 포함).
- 박천(博川): 위키백과 Pakchon County, Pakchon station 모두 좌표 없음. 대응 근거는 대백과 '신도'(E0032770: 박천 지역의 옛 지명, 청천강·대령강 하구 연안)만 확보.
- 의주(義州): Uiju County 페이지에 좌표 없음. 대백과 의주읍성(E0070816): 고려 때 용만현 또는 화의로 불렸다는 서술만 확보. 인접 참고점으로 신의주 행 수록.
- 숙천(肅川): Sukchon County, Sukchon station 모두 좌표 없음.
- 성천(成川) 군 중심, 강서(江西) 구역 중심: 군/구 좌표 없음. 각각 신성천역, 강서역 좌표를 '대략'으로 대체.
- 평원(平原), 용강(龍岡, Ryonggang County 좌표 없음), 함종, 삼등, 곡산(Koksan County 좌표 없음), 평성(1960년대 신도시로 판단되나 미확인)은 좌표 또는 고려 대응 근거 미확인.
- 요하(遼河) 하구(랴오둥만 유입부): 위키백과에 하구 좌표 없음. 합류점 두 곳만 있고 그중 본류 형성 지점(42°59′N 123°33′E)만 수록. 시랴오허 형성 지점(43°25′N 120°45′E)은 미수록.
- 랴오양 도심 좌표: 위키백과는 바이타공원 좌표만 제시.

## 서경 주변 지점 중 좌표 없는 것
- 서경 신호사(대백과 E0079117): 평양 서남쪽 약 4리 창광산이라는 서술만 있고 좌표 없음.
- 임원역(林原驛, 서경천도론 E0071271 언급): 현대 위치 비정 근거 미확보.

## 사료 원문의 거리·방향
- 세종실록지리지, 고려사 지리지의 평양부(서경) 사방 경계·거리 원문은 접근하지 못함(ko.wikisource 지리지 페이지 url_not_found, 검색 결과에 원문 페이지 없음). 따라서 CSV의 '서경과의 관계' 열은 순안(순화현) 한 행만 대백과 요약으로 채웠고 나머지는 빈칸.

## 대응이 학설로 갈리는지 확인하지 못한 항목
- 살수=청천강, 서경=평양은 '통설'로 표기했을 뿐 별설을 조사하지 못함.
- 압록강·요하의 고대 명칭(패수, 압록수, 요수)과 현 하천의 비정, 고구려 요동성과 현 랴오양의 비정은 이 표에서 다루지 않음.

## 웹 페이지 내 지시문
- 열람한 페이지에서 작업 지시처럼 보이는 문구는 발견하지 못함.
