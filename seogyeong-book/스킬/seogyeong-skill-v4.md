# 고전 지명 위치 추정서 서술요령 (v4)

이 문서는 《고려 서경(西京)의 위치를 추정하다: 여덟 가지 방법으로 동아시아 고전 지명을 좌표로 옮기기》(이광조 지음, 과학과영성출판사)를 만든 방식을 정리한 것이다. **이 문서만 읽고도** 다른 지역(다른 지명, 다른 왕조)에 같은 절차를 적용해 책 한 권 분량의 분석서를 만들 수 있도록, 원칙, 장 구성, 서술 규칙, 8기법의 핵심 식, 검증 절차, 데이터와 조판 파이프라인, 점검표를 모았다.

## 0. 먼저 할 일: 지역 카드 채우기

새 지역에 적용할 때는 아래 카드를 먼저 채운다. 빈칸이 있으면 해당 장은 "현재 판에는 수치를 싣지 않는다"고 쓰고 넘어간다. 값을 짐작으로 채우지 않는다.

| 대상 지명 | 한자, 한국 한자음, 시대 | 병음은 비교용 괄호에만 |
| 질문 | "얼마나 확실하게, 어떤 증거로 말할 수 있는가" 형식 | 학설 부정이 아님을 명시 |

| 사료 후보 | 정사, 지리지, 외국 사료, 사행록, 고지도, 금석문·고고 | 계통(누가 누구를 베꼈나) 표시 |
| 단위 환산 | 거리 단위(리, 보 등)의 km 사전구간 | 하나의 공유 변수로 취급 |

| 눈 가린 검증용 지명 | 위치가 확정된 지명 여러 곳 | 계산 중 좌표를 가린다 |
| 지리 자료 | 해안선, 하천, 산맥, DEM | 출처와 라이선스를 DB `geodata`에 기록 |

## 1. 불변 원칙 (어느 지역에나 적용)

1. **근거 중심.** 증거는 사료의 서술, 지리 자료, 계산 결과뿐이다. 근거를 확인할 수 없는 주장(권위, 전승, 인상)은 **가설**로 분류하고 같은 방법으로 검증하되 결론에 섞지 않는다.
2. **불확실성을 숨기지 않는다.** 점이 아니라 영역으로 말한다. 영역이 정직한지는 **보정 실험**으로 확인한다(95% 영역이 참을 95% 덮는가).
3. **지어내지 않는다.** 사료 구절, 쪽수, 서지, 수치를 기억으로 만들지 않는다. 확인하지 못한 것은 "원문 대조 전", "확인 중", "현재 판에는 수치를 싣지 않는다"로 적는다. 가상 세계의 수치는 모든 그림·표에 "가상 세계"라고 밝힌다.
4. **사람의 판단은 DB에 적는다.** 어느 구절을 증거로 삼았는지, 단위를 어떻게 환산했는지, 어느 지명을 같은 곳으로 보았는지를 출처와 함께 기록한다. 계산 이력(스크립트, 해시, 매개변수, 결과)도 저장한다.
5. **결과를 보기 전에 약속한다(사전 등록).** 증거 목록, 매개변수, 합치는 방식, 판정 기준을 날짜와 함께 기록한다. 바꾸면 이유와 전후 결과를 모두 보고한다.
6. **눈 가린 검증을 통과해야 신뢰구간이라 부른다.** 위치가 알려진 지명으로 같은 절차를 돌려 적중률을 센다.
7. **한국 한자음.** 한자 지명과 인명은 한국 한자음으로 읽고, 병음은 비교가 필요할 때 괄호로만 덧붙인다.
8. **인용은 APA 7판.** 본문은 (저자, 연도), 각 장 끝에 참고문헌. 서지가 확인되지 않은 항목은 목록 머리의 주석 줄에 "확인 중"이라 적고, 쪽수 단위 인용은 원문을 대조한 뒤에만 한다.
9. **직접 증거가 우선한다.** 발굴, 금석문 같은 직접 증거가 계산과 충돌하면 직접 증거를 우선한다.
10. **사료의 위치와 역사의 위치는 다르다.** 이 방법은 사료가 말하는 위치를 추정한다. 둘이 같다는 것은 별개의 가정임을 결론에 적는다.

기법별 장은 5장부터이고, 기법 번호는 장 번호와 4만큼 다르다(기법 1=5장 … 기법 8=12장). 표에서 혼동을 막으려면 "기법 번호는 장 번호가 아니다"를 주석으로 단다.

## 3. 서술 규칙

### 3.1 독자와 어조
- 독자는 **수학을 처음 보는 학자**다. 중학교 2학년이 따라올 수 있는 수준을 기준으로 삼는다.
- 정중한 평서문("…한다")으로 쓴다. 수사와 과장을 피하고, 가능한 한 짧은 문장을 쓴다.
- 새 용어는 처음 나올 때 **굵게** 쓰고 뜻을 풀어 준다. 영어 원어는 괄호로 한 번만 쓴다.
- 수식은 **뜻을 먼저 말한 뒤** 적는다. 수식 직후에 기호별 뜻을 풀어 준다.

### 3.2 모든 기법 장의 틀 (이 순서를 지킨다)
1. **직관적 소개**: 일상의 비유(조건 퍼즐, 낡은 지도 펴 놓기, 칸마다 그럴듯함 매기기 …)로 시작.
2. **이론 배경**: "이 아이디어는 어디서 왔는가"(과학사 이야기) → 핵심 식과 뜻 → 작은 예.
3. **연구가 걸어온 길**: 방법이 발전한 단계(보통 네 단계), 단계마다 "해결하려던 문제 → 핵심 아이디어 → 한계". 마지막에 **이 책이 빌려 온 것과 바꾼 것**, **풀리지 않은 문제**를 적는다.
4. **선행연구**: 인용한 고전 문헌을 갈래별로 정리. 해당 분야에서 지명 위치를 직접 다룬 연구는 DB 적재 뒤 대조표로 보강한다고 적는다.
5. **장난감 예제**: 가상 세계에서 방법을 끝까지 돌리고 그림과 표로 보인다. 보정 실험이 있는 기법은 여기서 한다.
6. **적용: 입력과 절차**: 새 지역에 쓸 때 필요한 입력 목록과 단계. 현재 판에서 비어 있으면 그렇게 적는다.
7. **한계와 오차**: 방법이 틀릴 수 있는 이유를 구체적으로. 숫자로 확인한 한계는 숫자를 쓴다.
8. **다음 기법과의 연결**.
9. **수식 풀이: 기호의 뜻과 해석**(아래 3.3) — 장 끝, 참고문헌 바로 앞.
10. 참고문헌(APA 7).

### 3.3 "수식 풀이" 절 쓰는 법 (5~12장 끝에 필수)
각 장에 나온 **모든 식**을 빠짐없이 다음 순서로 푼다.
1. **기호 사전**: 식에 나온 모든 기호의 뜻(첨자, 굵은 글씨, $\sum$, $\prod$, $\int$, $\propto$, $\lVert\ \rVert$ 포함). 굵은 $\mathbf{p}$는 "숫자 둘을 한 묶음으로 본 점"처럼 풀어 쓴다.
2. **말로 읽기**: 식을 문장으로 옮긴다("모든 간선에 대해, 어긋남의 제곱에 가중치를 곱해 더한다").
3. **작은 숫자 예**: 손으로 계산할 수 있는 크기(칸 4개, 점 2~3개)로 계산 과정을 끝까지 보인다. 검산이 가능한 값(예: $[2,3]+[4,6]=[6,9]$)을 쓰고, **계산기로 확인**한 뒤에 싣는다.
4. **해석과 교훈**: 숫자 예가 말해 주는 것(예: 올바른 순서로 곱하고 적분하면 더 큰 값이 나온다, 앵커가 둘뿐이면 거울 위치를 구별하지 못한다).
5. **이 장의 식을 응용하려면**: 연구자가 자기 자료에 쓰는 세 단계 요령.
부록 A에는 기호 읽는 법 표를 둔다.

### 3.4 연구사(2장)와 "연구가 걸어온 길" 쓰는 법
- 두 방식을 겹친다. **연대순**(사람과 저작)으로 따라가고, 이어서 **질문 중심**(어떤 질문, 어떤 근거, 근거가 어떻게 바뀌었는가)으로 분해한다.
- 시기를 나눈다(서경 책의 예: 관찬 지리지 → 고증학 → 근대·고고학 → 해방 후 남북 학계 → 비판·재검토 → 역사 지리 디지털화). 시기마다 "무엇이 새로 들어왔나"를 말한다.
- 학자의 주장은 "이렇게 주장했다"까지만 쓴다. **옳고 그름을 판정하지 않는다.** 판정 대신 근거의 종류(문헌, 지도, 고고, 계산)와 반증 조건을 장부에 적는다.
- 확인한 사실만 쓴다. 언론 해설 같은 **2차 서술**에서 얻은 사실은 그렇게 밝히고 세부 판정에는 쓰지 않는다. 쪽수 인용은 원문 대조 후에만 한다.
- 연구사에서 얻는 **교훈**을 마지막에 적는다(근거의 종류는 늘어 왔다, 같은 자료로 다른 결론이 나왔다, 학설은 "얼마나 확실한가"에 답하지 않았다).
- 학설 장부(가설 장부)의 열: 가설 번호, 위치 주장, 근거의 종류, 예측과 반증 조건. 증거 등급은 **A**(원문, 좌표, 계산 이력이 모두 DB에 있고 검증됨), **B**(일부 검증 전 또는 해석 폭이 큼), **C**(권위나 전승에 기대 확인 가능한 증거로 환원 안 됨; 틀렸다는 뜻이 아니라 지금 검정할 수 없다는 뜻).
- 주장의 형식 네 질문: 어디라고 주장하는가, 어떤 근거를 쓰는가, 검증 가능한 예측을 내놓는가, 어떤 관측이 나오면 틀렸다고 인정하는가. 3·4번에 답하지 못하면 가설로 분류한다.

### 3.5 분량
쪽수 제한은 없다. 충분히 설명하는 쪽을 택한다. 늘릴 곳: 연구사의 시기별 서술, 장난감 예제의 단계별 계산, 수식 풀이의 숫자 예, 한계 절의 구체적 사례.

### 3.6 결과가 비어 있을 때
숫자를 지어 메우지 않는다. 본문에 "현재 판에는 수치를 싣지 않는다"고 쓰고, **무엇이 채워지면 어떤 계산이 되는지** 절차로 적는다. 표의 계산하지 못한 칸은 "미산출"이라 쓰고 0이나 공백으로 두지 않는다.

## 4. 여덟 기법 카드 (핵심 식, 입력, 출력, 함정)

격자 위에서 일한다. 연구 지역을 칸으로 나누고 칸마다 "서경(대상 지명)이 여기일 가능성"을 계산한다. 서술의 단위(리 등) $u$ 하나를 모든 증거가 공유한다는 점이 8기법 전체의 공통 가정이다.

### 기법 1. 제약 만족과 구간 연산 (5장)
- **구간 연산**: $X+Y=[\underline x+\underline y,\ \overline x+\overline y]$, $X-Y=[\underline x-\overline y,\ \overline x-\underline y]$, $X\cdot Y=[\min,\max]$(네 끝 조합의 곱). 예: $490\text{리}\times[0.36,0.48]=[176.4,235.2]$ km.
- **의존성 문제**: 같은 불확실성($u$)을 식 안에서 두 번 따로 세면 구간이 부풀고 음수까지 생긴다. 하나의 불확실한 값은 모든 식에서 같은 값으로 다룬다.
- **해 영역**: $S=\bigcap_k\{\mathbf p\in D: c_k(\mathbf p)\}$ (조건 $c_k$를 모두 지키는 칸). 호 일관성은 고리 모양 핵과의 합성곱으로 계산한다.
- **최대 제약 만족**: 틀린 조건이 있을 수 있으면 "가장 많은 조건을 만족하는 칸"을 찾는다.
- **입력**: 거리·방위·포함·인접 서술의 구간. **출력**: 허용 칸의 집합과 면적.
- **함정**: 구간 환산을 따로 하면 영역이 지나치게 넓어진다. 필사 오류 하나가 해 전체를 지운다(최대 제약으로 대비).

### 기법 2. 기하 보간(지오레퍼런싱) (6장)
- 닮음 $f=sR\mathbf p+\mathbf t$(통제점 ≥2), 아핀 $f=A\mathbf p+\mathbf t$(≥3), 박판스플라인 $f=A\mathbf p+\mathbf t+\sum_i\mathbf w_i\varphi(\lVert\mathbf p-\mathbf p_i\rVert)$, $\varphi(r)=r^2\ln r$, 정칙화 $\lambda$는 핵행렬 평균 크기에 대한 상대값.
- **평가는 하나 빼고 맞추기(LOOCV) RMSE**로 한다. 맞춤 오차로 평가하지 않는다. 불확실성은 부트스트랩(서로 다른 점이 충분히 뽑힌 표본만). 국소 축척은 $\sqrt{|\det J|}$.
- **입력**: 옛 지도의 통제점 좌표쌍. **출력**: 대상 지명의 현대 좌표 점과 구름.
- **함정**: 통제점 짝이 틀렸거나 지도가 다른 지도를 베낀 오류는 구름에 안 들어간다. 학설에 따라 위치가 갈리는 지명은 통제점이 될 수 없다.

### 기법 3. 베이즈 추론과 몬테카를로 (7장)
- $P(\mathbf p\mid D)\propto P(D\mid\mathbf p)P(\mathbf p)$, 독립 증거는 $\prod_kP(L_k\mid\mathbf p)$.
- **거리 우도(올바른 모형)**: 사료 수치 $L$, 칸까지 실제 거리 $d(\mathbf p)$(km), 단위 $u$(km/리)일 때 $\ln L=\ln d(\mathbf p)-\ln u+\varepsilon$, $\varepsilon\sim N(0,\sigma^2)$. **칸에 의존하는 $1/d$ 인자를 붙이지 않는다**(붙이면 가까운 칸에 가산점이 생겨 95% 영역이 참을 74.5%밖에 덮지 못했다).
- **공유 단위**: $P(D\mid\mathbf p)=\int\prod_kP(L_k\mid\mathbf p,u)\,p(u)\,du$. **곱을 먼저, 적분을 나중에.**
- **필사 오류 대비 혼합 우도**: $(1-\varepsilon)\,\mathrm{LN}(L_k;d/u,\sigma)+\varepsilon\,P_{\text{넓음}}(L_k)$.
- 요약: 사후 평균, MAP, **HPD 영역**(확률 높은 칸부터 담아 합이 50%·95%). 메트로폴리스는 격자 계산의 검산 도구.
- **보정 실험**: 가상 세계 150개에서 신용 수준별 적중 비율과 영역 면적을 잰다.
- **함정**: 사전분포가 학설에서 오면 학설을 되풀이한다 → 기본은 균등 사전, 학설 사전은 따로 표시. 우도는 보정 실험으로만 검산된다.

### 기법 4. 최소비용 경로 (8장)
- 하이킹 함수 $v(S)=6\exp(-3.5\lvert S+0.05\rvert)$ km/h (경사 $S=\tan\theta$, 오르막 +). 8이웃 방향 그래프, 간선 비용 = 거리/속도. 데이크스트라로 출발 칸에서 모든 칸까지 최소 시간 $T(\mathbf p)$.
- **우도**: 서술 시간(예: 닷새 길 × 8시간 = 40시간)을 로그정규로 $\mathrm{LN}(40;T(\mathbf p),\sigma_T)$.
- 지형: Copernicus GLO-90을 0.9 km 격자로 평균(평균 때문에 이동시간이 짧게 나오는 편향이 있어 격자 크기를 바꿔 민감도 표시).
- **함정**: 하이킹 함수는 현대인 걷기 법칙이다. 나루, 관문, 계절, "하루 길"의 정의(사신 행렬? 파발?)를 담지 못한다. 하루 걷는 시간은 구간으로 둔다.

### 기법 5. 그래프 이론 (9장)
- 앵커를 고정한 **스트레스 최소화**: $\sum_{(a,b)\in E}w_{ab}(\lVert\mathbf z_a-\mathbf z_b\rVert-d_{ab})^2$. 서술이 구간이면 구간 밖으로 벗어난 만큼만 벌(중앙값 방식은 점 추정, 구간 방식은 불확실성).
- 간선 잭나이프(증거 하나씩 빼 보기), 매개중심성·페이지랭크로 검증 우선순위.
- **함정**: 앵커가 2개뿐이면 거울 위치를 구별 못 한다(≥3개, 일직선 아님). 잭나이프는 간선 구간 폭의 불확실성을 못 담아 영역이 **과소 포함**한다(가상 세계 보정에서 확인: T5 구간 under-coverage). 앵커가 틀리면 전체가 틀어진다.

### 기법 6. 시공간 지명 정합 (10장)
- 점수 $s=0.5\,s_{name}+0.3\,s_{time}+0.2\,s_{space}$, 기준 0.45 미만은 정합 실패. 헝가리 알고리즘으로 전체 점수 합 최대 짝짓기(욕심쟁이 선택은 같은 기록을 두 번 쓴다). **모호성 지수**(같은 시기·같은 이름의 서로 다른 지점 수) 저장.
- 시간 조각내기: 존속 기간을 시기별로 나눠 별개 기록으로 적는다.
- **함정**: 같은 이름이 다른 왕조의 다른 장소에 쓰였을 수 있다(이름 충돌). 시간·공간 자료 자체가 학설의 영향을 받는다. 가중치(0.5, 0.3, 0.2)는 편의 값이므로 바꿔 민감도를 본다.

### 기법 7. 지명 언어학적 추정 (11장)
- 핵밀도 $\rho_m(\mathbf p)=\sum_i\exp(-\lVert\mathbf p-\mathbf x_i\rVert^2/2h^2)$ ($h$ 기본 45 km), 평활 비율 $r_m=(\rho_m+\alpha\bar r_m)/(\rho_{all}+\alpha)$, 나이브 베이즈 $\Lambda(\mathbf p)=\prod_j r_{m_j}/\bar r_{m_j}$.
- 개명 짝 글자 대응 빈도는 **학설별로 대응표를 따로 저장하고 따로 계산**한다. 짝의 예시는 원문 대조 전에는 "방법의 예시"로만 쓴다.
- **함정**: 분포는 이주와 정착의 결과이지 도읍 위치가 아니다. 지명 목록은 기록에 남은 것만이라 표본이 치우친다 → 참고 증거의 지위.

### 기법 8. 다자료 교차검증 (12장)
- **로그 풀링** $p\propto\prod_kp_k^{w_k}$(날카롭지만 하나가 틀리면 참을 지움), **선형 풀링** $\sum_kw_kp_k$(안전하지만 흐림). 의존성 가중 $w_k$: 같은 증거를 공유하는 $n$개 기법에 $1/n$씩(서경 책의 장난감 세계: T1,T3,T5가 같은 거리 서술을 공유하므로 $w=(1/3,1,1/3,1,1/3,1,1)$). 어림법이며 근거를 DB에 적는다.
- **부딪침**: 겹침 계수 $\mathrm{OVL}=\sum\min(p,q)$, 하나 빼기(leave-one-out), 헬링거·KL.
- **증거 이론(뎀프스터–셰이퍼)**: 충돌량 $K$는 결과가 아니라 **경보**로만 쓴다(Zadeh, 1986). $K$가 크면 합치지 말고 14장 절차로 원인을 찾는다.
- **보정 실험 세 가지**: 정상 세계(공유 가정 맞음), 오염된 기법 하나가 섞인 세계, **가정이 틀린 세계**(참 단위가 가정 구간 밖: 모든 합치기가 흔들린다).
- **함정**: 공통 가정의 오류는 어떤 합치기로도 못 잡는다. 이것이 14장 3번 원인의 이유이다.

## 5. 통합 3부 (13~15장) 서술 요령

### 13장: 사전 등록과 눈 가린 검증
- 사전 등록 5항: ① 증거 목록(`ev_id`)과 제외 이유 ② 기법별 매개변수·격자 ③ 단위 사전구간과 필사 오류율 ε ④ 합치기 방식·가중·충돌 경보 기준 ⑤ H0 지지/기각 판정 기준. 바꾸면 이유와 날짜, 전후 결과를 모두 보고.
- 눈 가린 검증: 위치가 독립적으로 확정된 지명 → 좌표를 가리고 사료 서술만으로 8기법 → 좌표를 열어 적중률(보정) → 미달 기법은 가중을 낮추거나 입력을 고친다. 결과는 대상 지명 결과와 **같은 표에 나란히** 싣는다. 통과 못 한 도구로 낸 결과는 신뢰구간이라 쓰지 않는다.
- 비교표 형식: 중심(사후 평균, 10진 도), 면적(95% HPD, 조각 수), 미산출은 "미산출".

- **v2 추가**: 사전 등록 항목은 `run.params_json` 안에 evidence, excluded, grid, prior, pooling, criteria로 적고 **바꾸되 지우지 않는다**(status에 '대체됨'). 눈 가린 검증은 ① 독립 확정 ② 같은 종류의 사료 ③ 지역 분산 ④ 충분한 수 조건으로 지명을 고르고, **좌표 누출 점검표**(가린 좌표가 입력·기준점·지명 사전에 새지 않았는가)를 통과해야 한다. 적중률 $k/n$은 **윌슨 구간**으로 불확실성을 쓴다(n=10에서 9 적중도 0.60~0.98이므로 지명 50개 이상 권장). 판정 규칙(통과·약간 미달·크게 미달·판정 보류)도 계산 전에 등록한다. 입력이 없는 기법은 0이나 공백이 아니라 '미산출'.

### 14장: 충돌 분석 (다섯 원인, 다섯 단계)
- 원인: ① 입력 오류(`verified=0`부터 의심) ② 이름 충돌(다른 왕조의 같은 이름) ③ 공유 가정의 오류 ④ 모형의 한계 ⑤ 참된 이질성(시기·장소가 다른 서술).
- 단계: 경보 위치 찾기 → 입력 점검 → 공유 가정 변경(단위·시대·계통) → 증거 분할(계통별·시대별) → 기록(제외 전후 결과 모두 보고).
- 금기: 충돌 났다고 증거를 임의로 버리지 않는다. 충돌 없다고 맞다고 하지 않는다. 이질성을 평균으로 덮지 않고 둘 이상의 후보 영역은 그대로 보고한다.

- **v2 추가**: 원인별 징후·조치 표, 충돌 분석 보고 서식(경보 종류, 지목된 기법·증거, 단계별 점검, 원인 판단과 확신 정도, 제외한 증거의 전후 비교, 남은 불확실성). 이름 충돌은 `place_alias`에 후보를 모두 행으로 담고(name, place_id, period, state, source, verified) 후보별 조건부 결과를 보고한다. 단계별 설명에서 **실험으로 측정한 부분과 절차를 따라가 보기 위한 설명 예를 구분해 적는다**.

### 15장: 결론 문장과 지역 가설 사후 확률
- **결론 문장(빈칸 7개, 하나라도 비면 결론 없음)**: "사전 등록한 증거 집합 $E$ 아래에서, 대상 지명의 위치는 95% 신용영역 $R$(면적 $A$ km², 조각 $m$개) 안에 있다. 이 영역은 눈 가린 검증에서 명목 수준의 $c$%를 적중하였다. 지역 가설 H0~Hn의 사후 확률은 각각 …이다. 공유된 가정(단위 길이, 사료 계통, 시대)을 바꾼 민감도 계산에서 결론은 …였다."
- 지역 가설 사후: $P(H_j\mid D)\propto P(D\mid H_j)P(H_j)$, $P(D\mid H_j)=\sum_{\mathbf x\in R_j}P(D\mid\mathbf x)P(\mathbf x\mid H_j)$ (지역 안 균등 기본). **사전은 두 가지로 보고**: 무차별(모두 같음)과 보수적(H0 높음). 두 사전의 결론이 같으면 사전에 기대지 않는다. 다르면 증거 부족이라고 쓴다. 지역 경계를 바꾼 민감도를 함께 싣는다.
- 보고 순서: 눈 가린 검증 → 기법별·합친 영역 → 충돌 경보와 원인 → 지역 가설 사후(두 사전) → 공유 가정 민감도 → 남는 불확실성과 결과를 가장 크게 좁힐 자료 목록.
- 결과가 통설과 같든 다르든 **같은 형식**으로 보고한다고 약속한다.
- **v2 추가**: 사후 확률 계산 연습(임의의 숫자임을 표에 명시: 우도 8.0·1.0·0.5·0.5 $\times10^{-4}$ → 무차별 0.80/0.10/0.05/0.05, 보수적 0.966/0.017/0.009/0.009), 지역 크기 효과(오컴, 100칸 대 1,000칸이면 주변 우도 10배 차), 결과 유형별 보고 문장(하나로 모임·둘 이상 조각·가를 수 없음·검증 실패)과 피할 문장, 통설과 같은 결과든 다른 결과든 의심 강도를 같게.

## 6. 지역 장(16~19장) 틀

각 지역 장은 다음 순서로 쓴다.
1. **지역의 지리적 틀**: 지도 그림(하천·산맥 표시), 이 지역 가설이 책에서 갖는 지위.
2. **이 지역 가설이 예측하는 것**: 말을 **검정 가능한 예측**으로 번역한다. 기본 네 가지: ① 거리·방위 일관성(1·3·5기법) ② 지형 일관성(1·3기법, 하천·산) ③ 이동시간 일관성(4기법) ④ 이름·시기 일관성(6·7기법, 이름 충돌 배제). 예측이 하나도 안 틀려도 참이 아니고, 크게 틀리면 가설이 약해진다.
3. **입력 목록**: DB에 있어야 하는 것(독립 확정 지명 좌표, 서술, 지명 사전 기록, DEM·하천망, 옛 지도와 통제점).
4. **계산 절차**: 격자·경계 사전 등록 → 8기법 → 지역 허용 영역으로 자른 사후 → 가설 안 주변 우도 → 눈 가린 검증에 이 지역 지명 포함.
5. **이 지역의 함정**: H0은 "후광"(통설에 유리한 증거를 무의식적으로 고름, 지명 사전 좌표가 통설을 반영한 증거의 순환), 다른 지역은 "자료가 적어 영역이 넓음", "지명 이동·이름 충돌" 등 지역 고유의 위험을 구체적으로 쓴다.
6. **현재 판의 상태**: 증거가 DB에 있는지, 수치를 싣는지 여부를 정직하게 적는다.
7. **v2 추가 절**: ⑦ 이 지역을 읽는 눈(지형 질문 3가지) ⑧ 예측 판정표(예측 4개 × 맞을 때·틀릴 때의 모양·필요 자료) ⑨ 자료 수집 순서표(H0) 또는 지역 고유 표(H1 이름 충돌 후보, H2 해로·해안선·황하 유로 확장 항목, H3 계절별 하천 상태와 이름 후보) ⑩ 이 지역에서 특히 지킬 것(H0 확증 편향·공정한 계산, H1 이름이 같다는 사실을 증거로 쓰지 않음, H2 모형이 못 하는 것을 가설 약점으로 읽지 않음, H3 자료가 얇은 것과 가설이 틀린 것을 혼동하지 않음). 이름 후보 표는 일반 지식이므로 **원문 대조 전(verified=0)** 이라 표기하고 위치·연대를 단정하지 않는다.

| `geodata` | name, path, sha256, license, attribution | 지리 자료의 출처와 라이선스 |

**증거 채굴 절차**: ① 수집 스크립트가 원문을 `source_text`(verified=0)로 적재(출처 URL, 가져온 날짜, 판본) ② 연구자가 인쇄본·공인 전자 원문과 대조해 verified=1 ③ 구절에서 증거 유형별로 `evidence` 행을 뽑는다(한 구절에서 방위·거리·강 근접 증거를 각각) ④ 사료 계통도를 서문·범례에서 확인된 관계만으로 만들고 확인 안 된 관계는 "미확인" ⑤ 같은 계통이 같은 서술을 하면 증거 한 건으로 센다.

실행 순서(수치가 서로 엉키지 않게 이 순서를 지킨다):

4. 그림: `figs-a.py`, `figs-b.py`, `figs-c.py`.
5. 조판: `python3 tools/build.py color` 그리고 `bw` (`--quick`은 1회 패스).
6. `python3 tools/check-cites.py`로 본문 인용과 참고문헌 일치 점검(여러 단어 저자명은 거짓 경보가 날 수 있으니 눈으로 확인).

본문 수치는 손으로 옮기지 않는다. `{{키:서식}}` 매크로(예 `{{ch08.v0:.2f}}`, 리스트 인덱스는 `.1`)로 `numbers.json`에서 읽는다. 매크로 문자열을 문서에 그대로 보이려면 `\{\{키\}\}`로 쓴다.

장 본문에서 쓰는 매크로:
- `@@fig 경로|라벨|캡션@@` (예 `@@fig ch08/fig08-2-tobler | tobler | 토블러의 하이킹 함수.@@`)
- `@@tab csv이름|라벨|캡션|열서식|주석@@` (열서식 예 `p{20mm}p{36mm}R{14mm}`; 파일은 `표/csv이름.csv`, 모든 행의 열 수가 같아야 한다. 쉼표가 든 셀은 큰따옴표로 감싼다. 수식 셀은 `$…$` 안에서만 `^`, `_`를 쓴다)
- `@@refs chNN@@` (장 끝 참고문헌), 본문 참조는 `\figref{라벨}`, `\tabref{라벨}`.
- 마크다운 표(pipe table)는 쓰지 않는다. longtable 오류가 난다 → CSV 매크로로.
- 장 제목에 번호를 직접 쓰지 않는다(자동 번호). 서장과 부록은 `{-}`.
- 같은 라벨을 두 번 쓰지 않는다(`map16`~`map19`처럼 구분).

## 10. 그림과 지도 규칙

- 해안선·하천은 Natural Earth(공공 도메인) 실제 좌표. 손으로 찍지 않는다. 지도에는 **하천과 산맥이 보여야** 한다. Natural Earth만으로는 산맥·일부 하천이 거칠거나 빠지므로(예: 대동강 중심선 부재, 산맥 다각형이 과장) 그 판은 "임시판"이라 밝히고, DEM(Copernicus GLO-90)으로 고도대와 하천망을 더한 판을 환경이 되는 곳에서 만든다.

## 16. 책 폴더·DB·파싱 저장 규칙 (v2 신설)

**원칙: PDF는 결과물일 뿐이고, 수정은 PDF 밖에 따로 파싱해 저장한 내용에서 한다.**

1. **저장 위치**: 노트북 `C:\Users\UserK\Desktop\daily3\seogyeong-book\` 아래에 폴더 구조(8절)를 두고, PDF·DB·데이터·스킬을 모두 거기에 저장한다. 폴더에서 `git init`을 한 번 하고(노트북 PowerShell), 의미 있는 단계마다 커밋한다(커밋 메시지에 버전).

3. **파싱 저장 내용(book_ 표)**: `book_chapter`(장), `book_section`(절 — 제목 줄 포함 본문 `body_md`가 **수정 권위**), `book_block`(문단·목록·수식·그림·표 매크로 구분, 검색용 파생), `book_table`(CSV 원문), `book_figure`, `book_ref`(참고문헌 ↔ `paper`), `book_term`, `book_symbol`, `book_number`(numbers.json 평탄화), `hypothesis`, `book_skill`, `book_asset`, `book_revision`, 전문 검색 `book_fts`.
4. **수정 순서**: ① `python3 tools/db-edit.py DB find 검색어` → ② `list 장` → ③ `get 장 절번호`로 읽기 → ④ 고친 절을 파일로 저장해 `put 장 절번호 파일` → ⑤ `export 원고폴더`로 md 복원 → ⑥ 빌드 → ⑦ `mk-db.py`로 DB 재생성(블록·표·수치 갱신). `verify`가 "불일치 0"이면 DB와 원고가 같다.
5. **새 버전 납품 때마다**: 빌드(컬러·흑백) → `mk-db.py` → `book_asset`에 파일명·크기·sha256 기록 → 소스 묶음(tgz) → 폴더의 `pdf/`, `db/`, `소스/`, `스킬/`에 저장 → 스킬이 바뀌었으면 md·pdf 모두 새 버전으로.
6. **새 지역·새 책**: 폴더 이름만 바꾸고(예: `책이름-book`) 같은 구조와 같은 스크립트를 쓴다. 이 스킬(8~16절)이 곧 작업 규칙이다.
7. **파일 전달 제약**: 컨테이너에는 노트북 쉘이 없다. 노트북 폴더에는 장치 연결 도구로 파일을 써 넣고(폴더가 연결되어 있어야 함), 쓰기 전에 연결된 폴더 목록을 확인한다. 폴더 생성은 파일 쓰기 때 함께 만들어지는지 확인하고, 안 되면 PowerShell `mkdir` 한 줄을 안내한다. 컨테이너가 삭제되면 사라지므로 소스 묶음과 DB는 반드시 노트북에도 둔다.

## 17. 이 문서 자체의 상태

- 8기법 식과 보정 수치(예: 74.5%, 150개 가상 세계)는 서경 책의 가상 세계에서 얻은 값이다. 새 지역에서는 **같은 실험을 다시 돌려** 값을 갱신한다.
- 서경 책에서 아직 채우지 못한 것: 실제 사료 원문 적재와 대조, 서지 확인(Crossref 대조), 좌표 수집, DEM 기반 지도 판, 13~19장의 실제 증거.
- v2: 13~19장 보강 반영, 16절(폴더·DB·파싱 저장) 신설.
- v3: 서지 검증 절차 반영. `참고문헌/verified-v1.csv`(ch, author_key, year, doi, status, note)에 검증 결과를 적고 `mk-db.py`가 `book_ref.verified=1`로 반영한다. 서지 검증은 장별 저널 논문을 Crossref와 대조(제목·연도·학술지·권호·쪽수)하며, 책·1990년 이전 문헌·한국어 문헌은 NOTFOUND가 흔하므로 별도 원문 확인. 책은 v6까지 진행.

### 18.4 알려진 함정(추가)
- 노트북으로 보낸 셸 스크립트에서 `cp`로 같은 파일을 복사하면 `set -e` 때문에 첫 줄에서 멈춘다. 실행 위치와 복사 목적지를 분리한다.
