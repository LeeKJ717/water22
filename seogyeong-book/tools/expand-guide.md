# 확장 집필 지침 (책 4배 확장)

대상: /home/claude/book/원고/NN-*.md 한 장. 목표는 설명을 훨씬 친절하고 풍부하게 늘리는 것이다. 현재 분량의 4배 이상(공백 포함 글자 수 기준, 표/그림 줄 제외)을 목표로 하되 반복해서 늘리지 말고 매번 새 설명을 담는다.

## 반드시 지킬 규칙
1. 증거 기반. 새 문헌, 새 인용문, 새 통계, 새 연도, 새 수치를 지어내지 않는다. 장 안의 숫자와 매크로(`{{key:fmt}}`), 코드로 직접 계산한 숫자만 쓴다. 계산은 python으로 하고 결과를 본문에 옮긴다. 모르면 "이 책은 아직 모른다"라고 쓴다.
2. 독자는 중학교 2학년 수준. 용어는 처음 나올 때 쉬운 말로 풀고, 비유(일상의 예)를 쓰되 비유가 실제 수식과 어떻게 대응하는지 한 줄 덧붙인다. 한 문장에 한 생각.
3. 한자어는 한국 한자음으로 쓰고 처음에는 한자를 괄호로 단다. 중국어 병음은 쓰지 않는다(비교에 꼭 필요하면 괄호 안에만).
4. 기존 매크로 줄(`@@fig ...@@`, `@@tab ...@@`, `@@refs ...@@`, `Table:` 표, `<!--...-->` 마커, 생성 블록)은 지우거나 바꾸지 않는다. 새 표는 `Table: 캡션` + 빈 줄 + 마크다운 파이프 표 형식을 쓴다(표마다 캡션).
5. 수식은 pandoc 수학(`$...$`, `$$...$$`)을 쓰고 닫는 `$` 바로 뒤에 숫자가 오지 않게 한다. 숫자 쉼표는 수식 밖에서만.
6. 가상 세계 예제에는 "서경의 결과가 아니다"를 분명히 한다. 서경의 실제 값은 이 장의 자료(증거표)에 있는 것만 쓴다.
7. 새 절의 제목은 `##`(절)과 `###`(소절)를 쓴다. 장 제목(`#`)은 건드리지 않는다.
8. 파일 수정은 Edit 도구로 해당 위치에 삽입한다. 파일 전체를 다시 쓰지 않는다. 기존 문장은 문법 오류 외에는 고치지 않는다.

## 추가할 내용의 종류 (장마다 해당되는 것을 모두)
- 이 장을 한눈에 보기: 한 문단 요약과 핵심 질문 3~5개
- 쉬운 비유와 그림 같은 설명: 길 찾기, 요리, 시장, 학교 등 일상 비유를 충분히
- 개념을 하나씩 천천히: 정의 → 쉬운 말 → 숫자 예 → 흔한 오해 → 한 줄 정리
- 단계별 계산 예: 손으로 따라 할 수 있게 한 줄씩. 숫자는 코드로 검산
- 왜 이렇게 하는지(동기)와 하지 않으면 생기는 문제
- 흔히 하는 질문과 답(질의응답) 8개 이상
- 흔한 실수와 점검표
- 연습 문제와 풀이(풀이 숫자는 코드로 계산)
- 이 장의 요약과 다음 장으로 이어지는 말

## 구체적 사례 원칙 (최우선, 2차 지시)
개념만 설명하는 개론식 서술은 부족하다. 독자가 책을 덮고 자기 문제에 바로 응용할 수 있어야 한다. 그러므로:
1. 개념 하나마다 서로 다른 구체적 사례를 최소 3개 든다. 사례는 사료의 문형(거리 "동쪽으로 오십 리", 방위, 일정 "사흘 길", 하천·산·바다를 낀 서술, 여러 문헌이 어긋나는 경우), 오차의 크기(작은 경우와 큰 경우), 성공과 실패(반례)를 다르게 고른다.
2. 각 사례는 [원문(가상이면 가상이라고 표시)] → [읽는 법] → [입력 표] → [계산 한 줄씩(코드로 검산)] → [결과와 폭] → [해석과 주의] → [내 문제에 적용하는 점검표] 순서로 완결되게 쓴다.
3. 같은 방법을 다른 종류의 지명에 적용한 사례를 보인다(도읍, 성, 강나루, 고개, 섬, 사찰, 관청 터, 길목 등). 어떤 사례에서 방법이 잘 안 되는지도 보인다.
4. 실제 자료 사례는 이 책의 증거표(data/evidence-seogyeong-v1.csv)와 16장에 이미 적재된 것(각자성석, 장안성 면적, 고려사 문종 기사 인용 등)만 쓰고 층위(1·2·3층)를 밝힌다. 현대 지명의 좌표를 쓰려면 WebFetch로 위키백과 상자의 값을 직접 확인해 출처 URL을 본문에 (Wikipedia contributors, n.d.)로 달고 참고문헌 파일 참고문헌/chNN.txt에 APA 형식 한 줄을 추가한다. 확인하지 못한 값은 쓰지 않는다.
5. 사례를 늘릴 때 같은 틀에 숫자만 바꾼 반복은 사례로 치지 않는다. 사료 문형이나 상황이 달라야 한다.
6. 장 끝에 "내 문제에 적용하기" 절을 두고, 독자가 빈칸을 채우면 되는 작업지(입력 표 양식과 단계 체크리스트)를 제공한다.

## 1차 자료 우선 (3차 지시, 최우선)
구체적 사례는 1차 자료를 최대한 활용한다. 2차·3차 자료(연구서의 서술과 해석)는 비판적 해석이 필요할 때만, 따로 '비판적으로 읽기' 소절에서 쓰고 증거로 쓰지 않는다.
1. 사례의 원문은 data/evidence-seogyeong-v1.csv의 1층(옛 문헌 구절)과 2층(금석문 판독문)을 먼저 쓴다. 장안성 각자성석 5점(E8, E10~E12: 東十二里, 西向十日里, 下向□二里, □里四尺 등), 고려사 문종 35년 기사(E1: 서경에서 동서 10여 리), 삼국사기 고국원왕 13년 주(E3: 지금의 서경 동쪽 목멱산), 신증동국여지승람(E6: 대성산 동북쪽), 해동역사(E9: 구룡산 위)가 현재 확보된 것이다. 원문 한자와 판독 상태(□, 오기 가능성, 원문 대조 필요)를 그대로 옮긴다.
2. 가상 사례는 방법을 연습하는 용도로만 쓰고, 반드시 실제 사료의 문형('東十二里', '동서 각 10여 리', '대성산 동북쪽', '자차 동회')을 본떠서 만들며 '가상 사례'라고 첫 줄에 표시한다. 가상 사례의 숫자는 python으로 계산한다.
3. 1차 자료가 부족한 개념은 부족하다고 쓰고 '이 책이 앞으로 채울 사료' 목록에 넣는다. 부족한 것을 2·3차 해석으로 메우지 않는다.
4. 연구자의 해석(다나카의 좌궁설, 간지 해석, 장안성 위치 비정 등)은 '비판적으로 읽기'에서 어떤 근거로 어떻게 반론할 수 있는지 함께 쓰고, 사례 계산의 입력으로 쓰지 않는다.
5. 분권한다. 분량 제한은 없다. 설명은 충분히 친절하고 길게 쓴다.
